# 🐥 DOC Rate BD (Day Old Chick Rates Bangladesh)

বাংলাদেশের পোল্ট্রি খামারীদের জন্য প্রতিদিনের এক দিনের মুরগির বাচ্চা (Broiler, Sonali, Layer, Cockerel) এর লাইভ বাজারদর দেখার ও বুকিং করার একটি আধুনিক, মোবাইল-রেসপন্সিভ ওয়েব অ্যাপ্লিকেশন।

---

## 🚀 মূল ফিচারসমূহ (Key Features)

1. **লাইভ ডেইলি রেট ডিসপ্লে (Daily Chick Rates):**
   - কাজী (Kazi Farms), প্যারাগন (Paragon), নারিশ (Nourish), সিপি (CP), আফতাব (Aftab), কোয়ালিটি (Quality), প্রভিটা (Provita), আরআরপি (RRP) সহ শীর্ষস্থানীয় হ্যাচারির রেট।
   - আজকের রেট, গতকালের রেট এবং বাড়া-কমার ইন্ডিকেটর (+/- ৳)।
   - বিভাগভিত্তিক রেট ফিল্টারিং (ঢাকা, চট্টগ্রাম, রাজশাহী, খুলনা ইত্যাদি)।

2. **ইনবিল্ট এডমিন প্যানেল (Admin CMS):**
   - কোনো ডাটাবেজ সেটআপের ঝামেলা ছাড়াই ব্রাউজারে পিন কোড দিয়ে লগইন করে প্রতিদিনের রেট আপডেট করা যায়।
   - ডিফল্ট সিকিউরিটি পিন: `1234`।
   - নতুন কোম্পানি যোগ, রেট এডিট ও ডিলিট করার সুবিধা।
   - চলমান নোটিশ/বিজ্ঞপ্তি সরাসরি পরিবর্তন করার সুবিধা।
   - ব্যাকআপ JSON এক্সপোর্ট ও ইমপোর্ট করার ব্যবস্থা।

3. **বাচ্চা ও খামার লাভ-ক্ষতি ক্যালকুলেটর (Poultry Farm Profit Calculator):**
   - বাচ্চার সংখ্যা, বাচ্চার দর, ফিডের বস্তার দাম এবং মর্টালিটি রেট দিয়ে মোট খামার বাজেট এবং প্রত্যাশিত লাভ হিসাব করার টুল।

4. **সোশ্যাল মিডিয়া রেট শেয়ার জেনারেটর (Social Media Share Tool):**
   - প্রতিদিন সকালে এক ক্লিকে ফেসবুক পেজ বা হোয়াটসঅ্যাপ গ্রুপের জন্য সুন্দর ফরম্যাটেড রেট শিট কপি করার সুবিধা।

5. **সরাসরি বুকিং ও হোয়াটসঅ্যাপ অর্ডার (Direct WhatsApp Booking):**
   - খামারীদের সরাসরি কল দেওয়ার বাটন ও প্রাক-লিখিত মেসেজসহ হোয়াটসঅ্যাপ বুকিং রিকোয়েস্ট পাঠানোর সুবিধা।

6. **গত ৭ দিনের দামের ট্রেন্ড চার্ট (Price Trend Graph):**
   - ব্রয়লার ও সোনালী বাচ্চার দামের ওঠানামার ভিজ্যুয়াল গ্রাফ।

## 🛠️ প্রযুক্তি (Tech Stack)

- **Frontend:** React 19, Vite
- **Styling:** Tailwind CSS (v4)
- **Icons:** Lucide React
- **Storage:** Browser LocalStorage (Data persists across reloads)
- **Language Support:** বাংলা ও English (Bilingual)

## 💻 কিভাবে চালাবেন (How to Run)

প্রজেক্ট ফোল্ডারে প্রবেশ করুন:
```bash
cd C:\Users\PC\.gemini\antigravity\scratch\doc-rate-bd
```

লোকাল সার্ভার চালু করতে:
```bash
npm run dev
```
তারপর ব্রাউজারে `http://localhost:5173` ওপেন করুন।

বিল্ড করতে:
```bash
npm run build
```

## 🌐 লাইভ হোস্ট করার নিয়ম (Deploy to Web)

এই প্রজেক্টটি খুব সহজে সম্পূর্ণ ফ্রিতে হোস্ট করা যাবে:
1. **Vercel / Netlify:** প্রজেক্ট ফোল্ডারটি GitHub-এ পুশ করে Vercel বা Netlify-তে ইমপোর্ট করলে এক ক্লিকে লাইভ হয়ে যাবে।
2. **Firebase Hosting:** `firebase init hosting` চালিয়ে `dist` ফোল্ডার ডেপ্লয় করা যাবে।

# 🐥 DOC Rate BD (Day Old Chick Rates Bangladesh)

বাংলাদেশের পোল্ট্রি খামারীদের জন্য প্রতিদিনের এক দিনের মুরগির বাচ্চা (Broiler, Sonali, Layer, Cockerel) এর লাইভ বাজারদর দেখার ও বুকিং করার একটি আধুনিক, মোবাইল-রেসপন্সিভ ওয়েব অ্যাপ্লিকেশন।

---

## 🚀 মূল ফিচারসমূহ (Key Features)

1. **লাইভ ডেইলি রেট ডিসপ্লে (Daily Chick Rates):**
   - কাজী (Kazi Farms), প্যারাগন (Paragon), নারিশ (Nourish), সিপি (CP), আফতাব (Aftab), কোয়ালিটি (Quality), প্রভিটা (Provita), আরআরপি (RRP) সহ শীর্ষস্থানীয় হ্যাচারির রেট।
   - আজকের রেট, গতকালের রেট এবং বাড়া-কমার ইন্ডিকেটর (+/- ৳)।
   - বিভাগভিত্তিক রেট ফিল্টারিং (ঢাকা, চট্টগ্রাম, রাজশাহী, খুলনা ইত্যাদি)।

2. **এডমিন প্যানেল (Admin CMS) — রেট এখন সব ভিজিটরের কাছে পৌঁছায়:**
   - ওয়েবসাইটের নিচে 🔒 আইকনে ক্লিক করুন (অথবা URL-এর শেষে `#admin`, অথবা `Ctrl+Shift+A`)।
   - পাসওয়ার্ড **সার্ভারে** যাচাই হয় (`ADMIN_PASSWORD`)। কোডে/ব্রাউজারে কোনো পিন থাকে না।
   - বাচ্চার রেট, জোনভিত্তিক রেট, রেডি মুরগি ও ডিমের মোকাম রেট, নোটিশ, হটলাইন, তারিখ — সব এডিট করে **"প্রকাশ করুন"** চাপলে সব ভিজিটর নতুন রেট দেখে (সর্বোচ্চ ১-২ মিনিটে)।
   - **"নতুন দিন শুরু করুন"** বাটন: আজকের রেট গতকালের ঘরে সরিয়ে দেয়, ফলে কার্ডে ▲▼ পরিবর্তন দেখা যায়।
   - ভিজিটরদের মতামত শুধু এডমিন দেখতে পায় (পাবলিক API থেকে পড়া যায় না)।
   - ব্যাকআপ JSON এক্সপোর্ট ও ইমপোর্ট।

3. **বাচ্চা ও খামার লাভ-ক্ষতি ক্যালকুলেটর (Poultry Farm Profit Calculator):**
   - বাচ্চার সংখ্যা, বাচ্চার দর, ফিডের বস্তার দাম এবং মর্টালিটি রেট দিয়ে মোট খামার বাজেট এবং প্রত্যাশিত লাভ হিসাব করার টুল।

4. **সোশ্যাল মিডিয়া রেট শেয়ার জেনারেটর (Social Media Share Tool):**
   - প্রতিদিন সকালে এক ক্লিকে ফেসবুক পেজ বা হোয়াটসঅ্যাপ গ্রুপের জন্য সুন্দর ফরম্যাটেড রেট শিট কপি করার সুবিধা।

5. **সরাসরি বুকিং ও হোয়াটসঅ্যাপ অর্ডার (Direct WhatsApp Booking):**
   - খামারীদের সরাসরি কল দেওয়ার বাটন ও প্রাক-লিখিত মেসেজসহ হোয়াটসঅ্যাপ বুকিং রিকোয়েস্ট পাঠানোর সুবিধা।

6. **গত ৭ দিনের দামের ট্রেন্ড চার্ট (Price Trend Graph):**
   - ব্রয়লার ও সোনালী বাচ্চার দামের ওঠানামার ভিজ্যুয়াল গ্রাফ।

## 🛠️ প্রযুক্তি (Tech Stack)

- **Frontend:** React 19, Vite
- **Styling:** Tailwind CSS (v4)
- **Icons:** Lucide React
- **Backend (ফ্রি):** Vercel Serverless Functions (`/api`) + Vercel Blob (রেট ও মতামত সংরক্ষণ)
- **PWA:** মোবাইলে "Add to Home screen" করা যায়, অফলাইনে শেষ দেখা রেট দেখায়
- **Language Support:** বাংলা ও English (Bilingual)

## 🔐 প্রথমবার সেটআপ (জরুরি — একবারই করতে হবে)

1. **Vercel → আপনার প্রজেক্ট → Settings → Environment Variables**
2. নতুন ভ্যারিয়েবল যোগ করুন:
   - **Name:** `ADMIN_PASSWORD`
   - **Value:** একটি শক্ত পাসওয়ার্ড (১২+ অক্ষর, সংখ্যা ও অক্ষর মিশিয়ে)
   - Environment: Production (এবং Preview-তেও চাইলে)
3. **Deployments → সর্বশেষ ডেপ্লয় → Redeploy** করুন।
4. `BLOB_READ_WRITE_TOKEN` আগে থেকেই Vercel Blob (Storage ট্যাব) থেকে সংযুক্ত থাকলে আর কিছু লাগবে না।

> `ADMIN_PASSWORD` সেট না থাকলে এডমিন প্যানেল লক থাকে এবং সেটআপের নির্দেশনা দেখায়। সাইট যেমন ছিল তেমনই চলে।

### প্রতিদিনের কাজ (১ মিনিট)
1. 🔒 → পাসওয়ার্ড দিন → **"নতুন দিন শুরু করুন"**
2. কোম্পানির আজকের রেট বসান (দরকার হলে জোনভিত্তিক রেট)
3. **"প্রকাশ করুন"** চাপুন ✅

### রেট কতটা "লাইভ"?
- ডেটার তারিখ ২ দিনের বেশি পুরনো হলে সাইটে হলুদ সতর্কবার্তা আসে এবং "যাচাইকৃত" ব্যাজ "পুরনো রেট" হয়ে যায়।
- প্রকাশ করা রেট Vercel edge-এ ~৩০ সেকেন্ড ক্যাশ হয়।

### স্প্যাম ঠেকাতে (ঐচ্ছিক, ফ্রি)
Vercel → Firewall → Rate Limiting-এ `/api/feedback` (POST)-এর জন্য প্রতি IP-তে মিনিটে ৫টি রিকোয়েস্টের সীমা দিন।

## 💻 কিভাবে চালাবেন (How to Run)

প্রজেক্ট ফোল্ডারে প্রবেশ করুন:
```bash
git clone https://github.com/farhanshahriarabiribdu20/doc-rate-bd
cd doc-rate-bd
npm install
```

লোকাল সার্ভার চালু করতে:
```bash
npm run dev
```
তারপর ব্রাউজারে `http://localhost:5173` ওপেন করুন। (`/api` ফাংশনসহ পুরো সিস্টেম লোকালে চালাতে `npx vercel dev` ব্যবহার করুন এবং `.env.local`-এ `ADMIN_PASSWORD` ও `BLOB_READ_WRITE_TOKEN` দিন।)

বিল্ড করতে:
```bash
npm run build
```
